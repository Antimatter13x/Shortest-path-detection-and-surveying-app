# Shortest-path-detection-and-surveying-app

Our innovative method requires only one initial assessment before construction. Subsequent site changes are quickly updated in our database via a user-friendly interface. Surveying is accessible to anyone with a vehicle and a mobile phone, capturing real-time data on latitude, longitude, and soil type. Additional parameters like elevation, turning angle, and road width are derived from collected data and basic mobile phone functionalities. Data is securely stored in cloud platforms - Google Sheets. This dataset is used to construct a detailed roadmap around buildings, facilitating efficient calculation of the shortest path.
